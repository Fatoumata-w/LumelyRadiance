# Lumely Radiance - Site e-commerce de cosmétiques de luxe

##  Description
Lumely Radiance est un site web e-commerce fictif dédié aux cosmétiques de luxe.  
Ce projet a été réalisé dans le cadre de ma formation en informatique afin de mettre en pratique mes compétences en développement web (front-end et logique JavaScript).

Le site propose une expérience utilisateur moderne avec :
- une interface élégante
- un panier dynamique
- une simulation de paiement

---

##  Fonctionnalités

-  Page d’accueil avec présentation de la marque
-  Catalogue de produits (parfums, soins, cosmétiques)
-  Système de panier dynamique (ajout / suppression / total)
-  Simulation de paiement sécurisé
-  Formulaire de contact
-  Design responsive (adapté mobile)

---

##  Technologies utilisées

- HTML5  
- CSS3  
- JavaScript
